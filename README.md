# ❌⭕ Real-Time SignalR XO Game

A live two-player Tic-Tac-Toe application demonstrating real-time bi-directional communication using ASP.NET Core and SignalR hubs.

### 🚀 Features
- **Live Matchmaking / Room Code Support:** Join or create custom game rooms.
- **Bi-Directional Updates:** Move synchronization and turn indicators sent instantly over WebSockets.
- **Game State Validation:** Server-side turn checking, win-condition detection, and reset mechanics.
- **Connection Recovery:** Graceful handling of player disconnects and reconnects.
